## 1. 배경과 문제

- **주차 사고가 전체 자동차보험 물적 사고의 30.2%**, 지급 보험금의 25.7% (보험개발원, 2012~2014 분석)
  - 그중 **후진 중 53.8%**, **방향을 꺾는 중 61.5%** → 앱이 재는 신호가 정확히 사고가 나는 동작
- 초보·고령 운전자는 목적지보다 **주차장이 더 무섭다**. 좁은 회전 램프, 기둥, 기계식 정보는 블로그·커뮤니티 후기("○○백화점 초보 비추")에만 흩어져 있음
- 지하주차장에서 **몇 층에 댔는지 잊는 일**이 흔함. 아파트·백화점의 주차 위치 찾기는 건물에 카메라 설비가 있어야 함
- 구글 지도의 '주차 난이도'는 **빈자리를 찾기 어려운지**를 알려 줌 → **주차하는 동작 자체가 어려운지**는 아무도 안 알려 줌

## 7. 핵심 화면 상세

### C-02 도착지 난이도 카드 ⭐ (가장 중요 — 시연 첫 장면)
- **보여 줄 것 (우선순위 순)**
  1. 난이도 등급 — 크게 (★4.3 + "어려움" 라벨)
  2. 주차장 이름 ("○○백화점 지하주차장")
  3. 이유 태그 2~3개 — 아이콘 + 짧은 말 ("회전 램프 좁음", "평균 후진 3.2회", "기둥 많음")
  4. 근거 수치 — 작게 ("최근 30일 · 차량 142대 기준")
  5. 액션 — "더 쉬운 곳 보기" (주), "괜찮아요" (보조)
- **상태**
  - 쉬움(★1~2): 안심 톤, 액션은 "좋아요"만
  - 데이터 부족: "아직 기록이 적어요 (3대)" + 공공데이터 기반 기본 정보(기계식 여부 등)
  - 주차장 정보 없음: 카드 안 띄움
  - 주행 중: 상단 배너 한 줄로 축약 ("도착지 주차 ★4.3 어려움") — 터치 없음

### C-05 주차 완료 카드 ⭐
- **보여 줄 것**
  1. 추정 층 — 아주 크게 ("B3")
  2. 확인 질문 — "B3에 대셨나요?"
  3. 신뢰도 — 높음이면 "B3", 보통이면 "B3 (추정)", 낮음이면 층 버튼을 먼저 보여 줌
  4. 오늘 주차 한 줄 — "후진 2회 · 1분 40초 · 평소보다 쉬웠어요"
  5. 액션 — "맞아요" / "다른 층" / "구역도 기억하기" / "폰으로 보내기"
- **궤적 썸네일**: 카드 한쪽에 위에서 본 작은 동선 그림 (누르면 C-12)
- **원칙**: 시동 끄고 내리기 전 **3초 안에** 끝나야 함. 기본값 그대로 두면 자동 저장

### C-12 주차 궤적 리플레이 ⭐ (시연 영상에서 가장 눈에 띄는 장면)
- **배경 — 주차 구획 그림 (실제 도면 아님)**
  - 최종 주차 위치를 기준으로 주차 칸 1개를 그림 (국내 일반형 2.5m × 5.0m 비율)
  - 마지막으로 곧게 저속 주행한 구간 방향으로 **통로 띠**를 그림
  - 통로와 최종 차 방향의 각도로 **주차 형태 판별** → 직각(약 90°) / 평행(약 0°) / 사선(45~60°)에 맞춰 옆 칸을 이어 그림
- **전경 — 내 동선**
  - 전진 = 실선, 후진 = 점선 (색만으로 구분하지 않기)
  - 전진↔후진 전환점에 번호 ①②③
  - 최종 위치에 위에서 본 내 차 아이콘
  - 동선이 그려지는 애니메이션 (3~5초), "다시 보기"
- **하단 요약**: "후진 2회 · 핸들 3번 꺾음 · 1분 40초"
- **필수 문구**: "동선을 그림으로 다시 그렸어요" (실제 도면·실제 옆 차 위치처럼 보이면 안 됨)
- **시각 스타일**: 어라운드 뷰처럼 위에서 내려다본 깔끔한 일러스트. 실제 카메라 영상처럼 보이게 하지 않기
- **데이터 부족·오차 큼**: 궤적을 단순화(전환점만 잇기)하고 "대략적인 동선이에요" 표시

### C-06 층·구역 빠른 선택
- 키보드 금지. **큰 버튼 그리드**만 (층 한 줄, 구역 한 줄, 번호 3×4)
- 자주 쓰는 주차장은 그 주차장의 구역 체계를 미리 보여 줌 (예: 기둥 색 + 알파벳)

### C-08 주차장 상세
- 난이도 점수의 **근거를 시각화**: 평균 후진 횟수, 램프 회전 수, 진입~주차 평균 시간 — 막대 또는 게이지
- 층별 혼잡: "평일 오후 B1 만차 / B3부터 여유" — 층 막대
- 시간대별: 요일·시간 작은 히트맵
- 내 기록이 있으면 "나는 여기서 평균 후진 2회"

### C-09 내 주차 기록
- 리스트: 날짜, 장소, 층, 후진 횟수, 걸린 시간
- 월별 변화 작은 그래프 (평균 후진 횟수 추이)
- **카피 톤**: "실패" "못함" 금지. 좋아진 것만 강조

### M-01 폰 — 내 주차 위치
- 층·구역·기둥을 화면 절반 크기로 (주차장에서 걸으며 보는 화면)
- 주차 시각, 경과 시간 ("2시간 10분 전")
- 밝은 화면 기본 (지하가 어두움) + 다크모드 대응

## 9. 시각 언어 가이드

- **톤**: 안심, 응원, 차분함. 경고 앱처럼 보이면 안 됨 (빨간색 남용 금지)
- **난이도 5단계 표현** (색 + 숫자 + 형태를 함께)

| 등급 | 라벨 | 의미 |
|---|---|---|
| ★1 | 아주 쉬움 | 넓고 평면, 후진 거의 없음 |
| ★2 | 쉬움 | |
| ★3 | 보통 | |
| ★4 | 어려움 | 좁은 램프·기둥 많음 |
| ★5 | 아주 어려움 | 기계식·나선 램프 여러 바퀴·후진 잦음 |

- **이유 태그 아이콘 세트**: 회전 램프, 좁은 통로, 기둥 많음, 기계식, 경사 급함, 후진 잦음, 자리 넉넉, 평면 주차장, 층 많음
- **숫자**: 층(B3)·점수(4.3)는 이 앱의 주인공 → 크고 굵게, 고정폭 숫자
- **Pleos Connect 기본 UI와 어울리게**: 내비 위에 뜨는 배너·카드는 기존 시스템 UI를 해치지 않게

## 14. 기술 메모

- 사용하는 차량 신호: 조향각·브레이크·**기어**(Vehicle SDK), 차속(AAOS), 목적지·도착·경유지(NaviHelper)
- 화면 기기의 가속도·기압 센서는 **있으면 쓰는 선택 기능** → 층 추정 신뢰도가 '보통'으로 뜨는 경우가 있다는 전제
- 지하에서는 GPS가 약함 → 위치 지도는 쓰지 않고 **층·구역 텍스트 중심**
- 주행 중 화면은 플랫폼이 강제로 제한할 수 있음 → 주행 중 화면은 배너·아이콘만으로 완결
- **어라운드 뷰·카메라는 사용 불가** → 궤적은 차속·조향각·기어로 **계산해서 그린 그래픽**
  - 회전 속도 ≈ 차속 × tan(핸들 각도 ÷ 조향비) ÷ 축거 → 누적해서 (x, y, 방향)
  - 누적 오차로 **실제 도면 위 정확한 위치는 아님**
  - 시속 1~2km 이하에서 차속이 0으로 읽혀 막바지 오차가 큼 → AAOS `WHEEL_TICK`이 열려 있으면 정확도 개선
  - 조향비·축거는 차종별 공개 제원 표로 보정
  - 같은 계산의 회전 누적이 **층 추정(나선 램프 한 바퀴 = 한 층)**에도 쓰임
- Virtual Console로 차속을 직접 바꿀 수 있는지는 미확인 → 앱에 **녹화한 신호를 재생하는 리플레이 모드**를 넣어 시연
